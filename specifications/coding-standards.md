# Coding Standards

- TypeScript estrito.
- Tipos compartilhados em packages dedicados.
- Sem `any` sem justificativa.
- Erros estruturados.
- Logs estruturados.
- Funções pequenas e testáveis.
- Adapters para serviços externos.
- Domínio não deve depender diretamente de Telegram, Codex ou GitHub.
- Testes unitários para regras.
- Testes de integração para adapters e persistência.
- Atualizar documentação ao alterar contrato.
