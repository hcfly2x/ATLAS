# Non-Goals do MVP

O MVP do ATLAS não será:

- um IDE completo;
- um substituto do GitHub;
- um sistema de deploy genérico;
- um CRM;
- um ERP;
- um sistema de marketing completo;
- um conciliador financeiro;
- uma plataforma de cursos;
- uma plataforma multiusuário SaaS;
- um sistema de autonomia irrestrita.

O MVP deve apenas coordenar demandas, agentes, aprovação e execução local segura.
