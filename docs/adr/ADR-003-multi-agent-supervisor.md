# ADR-003 — Deliberação multiagente com supervisor

## Status
Aceito.

## Decisão
Agentes especializados produzem pareceres independentes. O supervisor resolve divergências e produz a decisão final.

## Motivo
Melhorar qualidade sem transformar a decisão em votação simples ou conversa indefinida.

## Consequências
Maior custo e latência; exige roteador de complexidade e limite de rodadas.
