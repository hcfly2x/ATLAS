# Histórico Consolidado do Projeto

## H001 — Origem
O projeto começou como uma integração Telegram → Codex.

## H002 — Worker local
Decidiu-se usar um serviço em nuvem para gateway e coordenação, com worker em notebook ou mini PC, sem expor diretamente a máquina local.

## H003 — Git isolado
Cada tarefa deve utilizar branch e worktree próprias.

## H004 — Multiagente
O projeto evoluiu para um conselho de agentes especializados.

## H005 — Supervisor
Um agente supervisor consolida pareceres e envia uma única especificação ao worker.

## H006 — Roteamento adaptativo
Tarefas simples não devem acionar o conselho completo.

## H007 — Portfólio
O ATLAS deve gerenciar o conciliador financeiro, a plataforma de curso, ele próprio e um futuro time de marketing.
