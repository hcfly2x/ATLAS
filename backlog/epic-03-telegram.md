# Epic 03 — Telegram MVP

> Trilha 1 — Fase 3.

## Tarefas
- webhook e autorização por Telegram ID único;
- texto para Task;
- seleção de projeto;
- botões de aprovação ligados ao alvo/hash;
- comando de status;
- cancelamento cooperativo;
- idempotency keys conforme decisão futura do ADR-012.

## Aceite
Uma tarefa pode ser criada, aprovada, acompanhada e cancelada pelo Telegram sem efeitos duplicados.
